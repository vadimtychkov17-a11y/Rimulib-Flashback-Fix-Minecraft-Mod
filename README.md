# Rimulib Flashback Fix

A lightweight Minecraft Fabric mod to fix compatibility crashes between Flashback and Rimulib.

## Features
- Prevents `IllegalStateException` crashes in Rimulib during Flashback replays.
- Requires Fabric Loader, Rimulib, The Shooting Star, and Flashback.
